# The words this system uses

Markova is read by children as young as twelve, by parents whose English is
their second or third language, and by staff in a hurry. Where a plain word
and a technical one mean the same thing, the plain word wins.

These are the substitutions made deliberately, and why. They are about what a
person reads on screen; the database columns, API fields and route paths keep
their original names, because renaming those would break bookmarks, break the
API and gain a reader nothing.

| Was | Now | Why |
| --- | --- | --- |
| Loan | Borrowed book | A loan is money. A child borrows a book. |
| Active loans | Books out | Says what it is: books not back yet. |
| Overdue loans | Books overdue | "Overdue" is kept; it is the word a library uses and everybody meets. |
| Days overdue | Days late | Plainer, and the number reads the same. |
| Checkout / Return | Give out and take back | Two verbs a child already has. |
| Books catalog | All books | "Catalog" is a librarian's word. |
| Total checkouts | Books given out | Counts a thing, not an event type. |
| Ticket | Request | Nobody outside a helpdesk has ever raised a ticket. |
| Support ticket | Help request | Says what it is for. |
| FAQ / FAQ articles | Common questions | An abbreviation of an English phrase, unpacked. |
| Bug report | Something is broken | What the person actually wants to say. |
| Feature request | Something is missing | Same. |

Words deliberately **kept**: aggregate, term, grade, and the rest of the
Rwandan report card, which are the terms the marksheet itself uses; a school
that had them replaced would not recognise its own report.
